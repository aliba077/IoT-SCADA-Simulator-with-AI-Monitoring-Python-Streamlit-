# IoT SCADA Simulator with AI Monitoring

##  Project Description
This is an industrial SCADA-style simulation system built using Python and Streamlit.  
It monitors simulated industrial parameters such as temperature, pressure, and vibration in real time.

---

##  Features
- Real-time industrial dashboard
- AI-based system diagnostics
- Alarm system (Normal / Warning / Critical)
- Operator control panel (Start / Stop / Emergency)
- Live data visualization (charts)
- Historical event logging
- Digital Twin simulation (IoT-ready architecture)

---

##  Technologies Used
- Python
- Streamlit
- Pandas
- Random data simulation
- Streamlit Autorefresh

---

##  Purpose
This project simulates a real industrial SCADA system and prepares architecture for future IoT integration (ESP32 / sensors).
